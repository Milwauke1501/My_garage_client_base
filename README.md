# Гараж — інструкція із запуску

## Що в архіві
- `index.html` — сам застосунок
- `manifest.json` — опис PWA (назва, іконка, колір)
- `sw.js` — service worker для офлайн-роботи
- `icon-192.png`, `icon-512.png` — іконки

## Крок 1. Google Cloud (для входу і Google Drive)
1. Відкрийте console.cloud.google.com → створіть новий проєкт.
2. «APIs & Services» → «Library» → знайдіть **Google Drive API** → Enable.
3. «APIs & Services» → «Credentials» → «Create Credentials» → **OAuth client ID**.
   - Application type: **Web application**
   - Authorized JavaScript origins: URL, де буде розміщено сайт (наприклад `https://ваш-акаунт.github.io`)
4. Скопіюйте Client ID (закінчується на `.apps.googleusercontent.com`).
5. Ще потрібен OAuth consent screen: заповніть назву застосунку, додайте себе як тестового користувача (поки застосунок не проходив верифікацію Google, входити зможуть лише додані вами тестові акаунти — цього достатньо для особистого використання).
6. Відкрийте `index.html`, знайдіть рядок:
   ```
   const GOOGLE_CLIENT_ID = 'ВСТАВТЕ_СЮДИ_ВАШ_CLIENT_ID.apps.googleusercontent.com';
   ```
   і вставте свій Client ID.

## Крок 2. Розмістити сайт (потрібен HTTPS)
Найпростіше — GitHub Pages, безкоштовно:
1. Створіть репозиторій на GitHub, залийте туди всі файли з цієї папки.
2. Settings → Pages → Source: гілка `main`, папка `/root`.
3. За хвилину отримаєте посилання типу `https://ваш-акаунт.github.io/назва-репо/`.
4. Це посилання додайте в Authorized JavaScript origins у Google Cloud (Крок 1.3).

(Netlify чи Firebase Hosting теж підходять, якщо звичніші.)

## Крок 3. Встановити як застосунок
- **Android (Chrome):** відкрийте посилання → меню (⋮) → «Встановити застосунок» / «Додати на головний екран». З'явиться повноцінна іконка, застосунок відкривається окремим вікном, працює офлайн.
- **Windows (Edge або Chrome):** відкрийте посилання → іконка встановлення в адресному рядку → «Встановити». З'явиться у меню «Пуск» як окрема програма.

## Крок 4 (опційно). Отримати справжній .apk-файл
Якщо потрібен саме файл `.apk`, а не встановлення з браузера:
1. Зайдіть на **pwabuilder.com**.
2. Вставте посилання на ваш сайт (з Кроку 2).
3. Натисніть «Package for stores» → Android.
4. Сервіс згенерує готовий `.apk`/`.aab`, який можна встановити напряму на телефон або залити в Google Play.

## Синхронізація
Кнопка «Увійти» у застосунку відкриває вхід через Google. Після дозволу на доступ дані зберігаються у файлі `garage_data.json` у вашому Google Drive (застосунок бачить лише файли, які сам створив — не весь диск). На будь-якому іншому пристрої достатньо увійти тим самим акаунтом, щоб підтягнути ті самі дані.

Без входу застосунок так само працює — дані просто зберігаються локально на пристрої.
